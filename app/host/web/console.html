音乐库文件夹
可以添加多个文件夹。最多向下扫描 5 层子目录；只索引文件名与大小，控制台不列曲目，上万首也不会卡。
大于 24M 的歌曲文件会被转码
为什么要转码：若琪是 Android 4.4，自带解码器只保证 16-bit / ≤48 kHz 的 FLAC，单次下载还有体积上限。高解析母带（24-bit / 96 kHz、几十 MB 一首）直接送过去会播放失败或中途退出，所以要在这一首即将播放时先转成设备必定能播的小文件。
什么样的文件会被转码：本地音乐满足任意一条就会转 —— 位深 >16 bit、采样率 >48 kHz、单个文件 >24 MB。转成 44.1 kHz / 256 kbps 的 AAC（约 7 MB），下载快也不挑格式；16-bit / ≤48 kHz 且 ≤24 MB 的文件原样直连，无损不变。AAC 有损只作用于这一份播放副本。
音乐库原始文件不会被改动：全程只读源文件，转码副本写在本项目 runtime 缓存里、1 小时后自动清理；不改名、不覆盖、不移动、不删除任何一首歌，也不会往音乐文件夹里写索引或缓存。
