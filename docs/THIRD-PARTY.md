# 分发内容
项目原创代码与文档采用根目录 LICENSE 的 MIT 条款。Rokid、OpenAI、Anthropic、Home Assistant 等名称用于标识兼容产品。项目独立维护。
设备端 HA 图标附带 app/android/assets/ha-mdi-license.txt。拓竹 LAN 公共信任证书用于校验打印机证书，与用户的打印机访问码分开。待机时钟在公开树中使用 Android 系统字体。
Mac 本机构建嵌入 CPython、PyInstaller bootloader 与 paho-mqtt，相关运行时依赖遵循各自上游条款。向第三方分发二进制前需随成品附齐这些版本的许可证。adb 由使用者从 Android 官方获取。助手 CLI、账号、模型、N.E.K.O.、原厂固件和原厂应用由使用者自行提供。
