# Rokid-Allen-Unbricked

![若琪外星人项目封面：左侧是白色若琪外星人智能音箱，右侧九宫格展示 Hermes、WorkBuddy、DeepSeek、ChatGPT、Rokid、Gemini、N.E.K.O.、Home Assistant、Claude 九个助手头像，标注 Rokid Allen。](docs/images/rokid-allen-cover.png)

**让老若琪重新开口。** 把 2018 年的若琪外星人 RH01CW（系统型号 ROKID-R2，Android 4.4 / API 19）接到 Mac，继续用它的原厂唤醒、麦克风和曲面屏。Mac 运行 AI 助手、音乐和本地查询服务，若琪负责接收语音、播报回复和显示卡片。

项目基于 v0.3.0 整理，目前开放试装测试。同步私有开发仓库 `Rokid-Allen-Revive` 的功能与版本，两仓库版本号保持一致。

## 若琪现在能做什么

| 功能 | 使用体验 |
| --- | --- |
| **多助手语音** | 想让谁回答或帮你处理任务，就喊谁的名字。可配置 Hermes、GPT（Codex）、大肥鱼（DeepSeek/DSH）、巴蒂（WorkBuddy）、猫娘（N.E.K.O.）、小家（Home Assistant）、克劳德（Claude Code）和哈基米（Gemini）。各后端使用自己的软件或账号。 |
| **音乐与 Roon** | 语音点歌时可以先找局域网音乐库，没找到再搜索配置好的在线来源。通过 N.E.K.O. 接入网易云音乐或 QQ 音乐，按服务要求登录。配置独立 Roon 扩展后，可语音控制家里已有的播放区。 |
| **天气与表盘** | 保留原生天气页面和动效的使用思路。恢复查询需要原设备具备相应的天气配置。项目也保留可切换表盘的独立待机时钟源码，随基础版首次安装部署的是 Bridge。 |
| **智能家居** | 配置 Home Assistant 后，通过“若琪”或“小家”查询和控制已接入的设备。其他助手遇到家居指令会提示找小家。支持在屏幕上显示常见开关和查询的反馈卡片。 |
| **小应用** | 在 Mac 控制台的应用商店管理小应用。若琪屏幕可显示 Codex 用量、Mac CPU 和内存、网速，以及兼容拓竹打印机的局域网打印进度。 |
| **猫娘的语音入口** | 配置 N.E.K.O. 和桥接插件后，可以用若琪的麦克风唤醒猫娘、接续对话。将设备摄像头用于猫娘视觉仍在探索。 |
| **通知播报**（实验性） | 控制台「设置 → 通知播报」可让 Mac 通知在若琪上弹卡片并播报。默认全部关闭；可勾选日历、提醒事项或本机已安装应用，逐项选择只弹卡片或播报标题/正文，并预览或静音测试。本机不保存真实通知正文。公开版目前提供接收与播报链路；macOS 辅助功能读取器需自行编译并授权后才会推送通知，详见下文。 |

**首次使用请先固化 ADB。** 网络调试是这款老设备的重要维护通道。打开 Mac App，输入若琪的局域网 IPv4，再点击“连接并固化 ADB”。App 核对机型、厂商和 API 等级，检查持久端口，按需保存 5555 并回读。通过后才开放安装按钮。安装时需要设备已能联网，并已开放 ADB。

## 首次安装

1. 准备一台在同一可信网络的 Mac 和若琪，确认机身型号、路由器分配的音箱 IP，且网络 ADB 已由机主开启。安装 Google 提供的 macOS Platform-Tools，保留完整下载目录。[Android 官方下载](https://developer.android.com/tools/releases/platform-tools)
2. 当前可从源码构建本地测试包。按[本机构建指南](docs/PACKAGING.md)制作 Mac App，打开后输入若琪 IP。App 内可点“下载 Mac 版 Platform-Tools”。在官方页面选 Mac 版，解压后点“选择 adb…”，选择 `platform-tools` 文件夹或里面的 `adb`。已有项目与新项目不要同时驱动同一台音箱。
3. 点“连接并固化 ADB”。如果持久属性已是 5555，App 只读检查。如果尚未固化，需要固件已报告 ADB 密钥认证，并且当前授权 shell 有属性写权限。任何检查失败都会显示原因并停止。不要将 5555 暴露到公网；旧固件可能没有 ADB 密钥认证。
4. “已回读”表示本次连接看到正确的属性值。若要验证跨重启，先准备好可用的本地恢复方式，由机主自行正常重启，重新输入同一 IP 并校验；App 比对设备记录和启动标识。向导不会代为重启。
5. 点“安装 Bridge 并打开控制台”。安装器只连接已选音箱，检查同版 APK、通过 ADB 配对，再启动本项目 Host 与语音监听。已安装旧开发包时，若证书不同，保留旧包并报告冲突；先核实自己的签名与备份。控制台地址为本机的 `http://127.0.0.1:18765/console`。说“若琪，查询系统资源”可检查首张卡片。
6. 关闭 App 窗口可停止它启动的 Mac 服务。配对和助手配置保存在当前用户的“资源库 → Application Support → Rokid-Allen-Unbricked”。机主可在 Android 应用管理中单独移除若琪助手。卸载 Bridge 或退出 Mac App 后，持久 ADB 属性仍保留。

设备协议使用家庭局域网 HTTP，请使用自己管理的可信网络。控制台管理凭据和设备凭据分别生成，账号信息在本机录入。Mac App 的基础安装范围是设备桥接与控制台。
