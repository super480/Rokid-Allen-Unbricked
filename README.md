# Rokid-Allen-Unbricked

让 2018 年的若琪 RH01CW（系统型号 ROKID-R2，Android 4.4 / API 19）继续做一台能听、能说、能显示卡片的桌面助手。若琪负责原厂唤醒、语音与屏幕，Mac 负责运行助手、控制台和本地查询。项目从 v0.2.7（594be2e）整理而来，是独立的社区项目。

**首次使用请先固化 ADB。** 网络调试是这款老设备的重要维护通道。设备当前能连接，重启后仍有可能失去 ADB。Mac App 打开先输入若琪的局域网 IPv4，点击“连接并固化 ADB”。它会核对机型、厂商和 API 等级，检查持久端口，需要时保存 5555 并回读。只有这一步通过才开放安装按钮。固化可以降低重启失联的风险；它不能恢复已经无法启动、无法联网或从未开放 ADB 的设备。

## 这一版可以做什么

- 通过同一控制台选择 Hermes、GPT（Codex）、大肥鱼（DSH）、巴蒂（WorkBuddy）、猫娘（N.E.K.O.）、小家（Home Assistant）、克劳德（Claude Code）。各后端使用机主自己的软件或账号。
- 查询 Mac 的 CPU、内存和网速；读取已登录 Codex 的用量窗口；配置兼容的拓竹打印机后查看进度。原生卡片在若琪屏幕上绘制。
- 接入自己的 Home Assistant，通过“小家”交互、查看设备反馈；使用猫娘需要另装 N.E.K.O. 与本项目桥接插件。Roon 扩展、待机时钟源码独立保留。基础安装只部署 Bridge。
- 在 Mac 浏览器管理助手、唤醒词、小应用和连接设置。Mac 需要保持在线，原厂语音识别／播报仍受固件及原厂服务可用性影响。

## 首次安装

1. 准备一台在同一可信网络的 Mac 和若琪，确认机身型号、路由器分配的音箱 IP，且网络 ADB 已由机主开启。安装 Google 提供的 macOS Platform-Tools，保留完整下载目录。[Android 官方下载](https://developer.android.com/tools/releases/platform-tools)
2. 当前公开交付是源码。按[本机构建指南](docs/PACKAGING.md)制作 Mac App，打开后输入若琪 IP。必要时点“选择 adb…”指定官方工具。已有项目与新项目不要同时驱动同一台音箱。
3. 点“连接并固化 ADB”。如果持久属性已是 5555，App 只读检查。如果尚未固化，需要固件已报告 ADB 密钥认证，并且当前授权 shell 有属性写权限。任何检查失败都会显示原因并停止。不要将 5555 暴露到公网；旧固件可能没有 ADB 密钥认证。
4. “已回读”表示本次连接看到正确的属性值。若要验证跨重启，先准备好可用的本地恢复方式，由机主自行正常重启，重新输入同一 IP 并校验；App 比对设备记录和启动标识。向导不会代为重启。
5. 点“安装 Bridge 并打开控制台”。安装器只连接已选音箱，检查同版 APK、通过 ADB 配对，再启动本项目 Host 与语音监听。已安装旧开发包时，若证书不同，保留旧包并报告冲突；先核实自己的签名与备份。控制台地址为本机的 `http://127.0.0.1:18765/console`。说“若琪，查询系统资源”可检查首张卡片。
6. 关闭 App 窗口可停止它启动的 Mac 服务。配对和助手配置保存在当前用户的“资源库 → Application Support → Rokid-Allen-Unbricked”。机主可在 Android 应用管理中单独移除若琪助手。卸载 Bridge 或退出 Mac App 后，持久 ADB 属性仍保留。

设备协议使用家庭局域网 HTTP；请使用自己管理的可信网络。控制台管理凭据和设备凭据分别生成，账号信息在本机录入。公开版不自动改写原厂天气的 hosts、系统证书或网络规则，也不替换原厂待机应用。
